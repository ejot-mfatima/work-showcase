# Work showcase — Time Tracking · Task Management · Risk Management

Presentation of three projects on the EJOT Engineering Platform (EOS).

## Open

Open `index.html` in a browser. Everything is local (reveal.js is vendored), so it works offline.

| Key | Action |
| --- | --- |
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `S` | Speaker view with notes and timer |
| `F` | Full screen |
| `O` | Slide overview |
| Click a screenshot | Zoom in (click or `Esc` to close) |

## Structure

1. Opening — agenda and the three projects at a glance
2. Time Tracking — objective, approach, delivery, own additions, status
3. Task Management — objective, approach, delivery, own additions, status
4. Risk Management — objective, approach, delivery, own additions, status
5. Summary, outlook, questions

## PDF copy

Open `index.html?print-pdf` in Chrome and print to PDF (landscape, no margins, background graphics on).
